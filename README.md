# Client Ticket Management System (SQL Project)

## 📌 Overview
The **Client Ticket Management System** is a SQL-based project designed to manage client support tickets, engineer assignments, and activity logs for remote support teams.  
It helps software or IT companies efficiently handle customer issues, assign support engineers, and track resolution progress.

---

## 🧱 Database Design
The project includes four main tables:
1. **Clients** – Stores client details.
2. **Engineers** – Contains engineer information.
3. **Tickets** – Tracks issues reported by clients.
4. **ActivityLog** – Logs all ticket-related activities.

---

## 🧠 Features
- Client registration and support tracking  
- Engineer assignment to tickets  
- Ticket status management (Open, In Progress, Resolved)  
- Activity log for each ticket update  
- SQL reports for performance analysis and resolution time  

---

## ⚙️ Technologies Used
- **Database:** MySQL / SQL Server  
- **Tools:** MySQL Workbench / SSMS  
- **Language:** SQL  

---

## 🗃️ How to Use
1. Run `database_schema.sql` to create tables.  
2. Execute `sample_data.sql` to insert example data.  
3. Run `example_queries.sql` to explore functionality.  

---

## 📊 Example Reports
- List of open and in-progress tickets  
- Monthly resolved ticket count
