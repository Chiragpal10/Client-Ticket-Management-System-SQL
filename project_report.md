# Project Report – Client Ticket Management System (SQL)

## Objective
To design a relational database that helps a remote support team manage and resolve client issues efficiently.

## Key Features
- Tracks client issues and ticket progress.
- Assigns engineers based on specialization.
- Logs every action for accountability.
- Generates SQL reports for management insights.

## Learning Outcomes
- SQL schema design and normalization.
- Query optimization and troubleshooting.
- Real-world data management experience.
- Improved understanding of remote support workflows.

## Tools Used
- MySQL / SQL Server
- SSMS / MySQL Workbench
